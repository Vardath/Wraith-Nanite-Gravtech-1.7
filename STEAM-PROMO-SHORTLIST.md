# WNG Steam Workshop promo-art shortlist

Use the current **About/Preview.png** as the Workshop thumbnail/logo.

For the Workshop description, keep the media short and strong rather than dumping the entire gallery. The current live gallery is:
https://vardath.github.io/wng-art.html

## 1. Replicator hierarchy — strongest mechanics image
**Show:** Drone -> Hunter -> Bulwark -> Titan -> Siege Mass together, ideally as an in-game lineup or one clean composite.

Current source art:
- Textures/Things/Pawn/Replicator/WNG_ReplicatorDrone.png
- Textures/Things/Pawn/Replicator/WNG_ReplicatorHunter.png

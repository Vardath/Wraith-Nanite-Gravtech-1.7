# WNG 1.6 / 1.7 Waylith port

Source: Vardath/Wraith-Nanite-Gravtech-1.6 main, snapshot copied by bootstrap workflow.
Common Defs, Patches, Textures, Sounds and optional CE patches load from mod root.
The 1.6 and 1.7 Assemblies directories are mutually exclusive in LoadFolders.xml.
1.6 assembly is preserved byte-for-byte from the source repository.
1.7 source targets net10.0, Krafs.Rimworld.Ref 1.7.4977-alpha.1, and Lib.Harmony 3.0.0-rc.2.
Experimental 1.7 compatibility: requires Waylith runtime testing and dependency verification before Workshop signoff.
Z Adaptive companion inside the repository is preserved as 1.6 source and has NOT been ported to 1.7.

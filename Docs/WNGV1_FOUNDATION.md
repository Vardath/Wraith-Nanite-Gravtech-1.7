# WNGv1 Foundation Notes

This is the clean-restart implementation. Historical WNG code is not copied into this tree unless a specific retained asset or implementation idea is deliberately reviewed and accepted.

First implementation sequence:
1. Replicator matter/resource identity;
2. block Replicator pawn/control foundation;
3. ordinary environmental assimilation + its two-Drone reproduction as one atomic transaction (no loose-Block output);
4. genuine destruction salvage / loose-Block hazard and reassembly as a separate system;
5. hierarchy recombination/splitting;
6. EMP/suppression/containment;
7. adaptation;
8. specialists/incidents/faction only after the foundation is proven.

Every architectural choice must be justified in `/mnt/data/WNGv1/DECISION_LOG.md`.

## Wraith lineage / strategic-hunger boundary — 2026-09-14

Wraith identity remains one xenotype with caste PawnKinds. The clean build now adds four independent native factions (Sable Brood, Cinder Court, Veiled Hive, Pale Covenant), one-time native inter-lineage goodwill initialization, and faction-specific strategic hunger.

Strategic hunger is the only system allowed to create the faction feeding-request UI. Ordinary pawn `Drain Life`/`Partial Feed` and future Mature-Hive local feeding ecology are separate. Requests use exact saved prisoner references and exact named Wraith world pawns in a force-paused two-stage decision. Refusal/unresolved hunger builds faction-specific pressure; pressure can become a native Wraith raid only when that faction is hostile. Accepted controlled feeding is transactional and rolls back biological/resource changes on commit failure.

## Player Growth Chamber boundary — 2026-09-15

The player Growth Chamber is now dedicated demographic infrastructure. It is cultivated directly at the Living Forge as a complete minified chamber; no Growth Chamber Seed/planting stage exists in the clean path. Hunter/Warrior/Keeper player gestation keeps the recovered Biomass/time and Life Force donor costs; any living, conscious player Wraith, including an independent scenario-start Hunter, can now initiate a paid cycle. Queen is also available as a deliberately higher-cost caste (460 biomass and 360,000 ticks before substructure efficiency). Commander still requires its separate Wraith biological template. A gestated Queen is a new player pawn, not a promotion or transformation of the initiating Hunter. The chamber does not physically store the Hunter: it authorizes gestation while the required active Wraith donor supplies Life Force, and produces a separate newborn pawn at cycle completion.

A Growth Chamber fully installed on native grav substructure snapshots the accepted 0.70 Biomass / 0.65 duration efficiency factors when a cycle begins. Player gestation does not inherit NPC Mature-Hive founding-population caps and does not modify strategic faction hunger. Child's Toy remains native Biotech gestation.

Commander is an ordinary Wraith caste and is implemented in the player Growth Chamber. Commander gestation consumes an existing Wraith biological template (a Wraith corpse or living Wraith prisoner), costs 340 base Biomass, takes 300,000 base ticks before grav-substructure efficiency, and retains the chamber's normal Life Force donor requirement and paid-cycle save/retry safeguards.

## 2026-10-14 Asuran Replicator-block fabrication eligibility

The active WNG_NaniteReserve gene now grants the existing resource-paid fabricate-Replicator-blocks ability via native gene ability routing. This covers all Asuran castes, normal and copied human-form Replicators, and custom xenotypes bearing that gene. The old two-xenotype collective-link grant/remove logic was deleted so it cannot strip the ability from legitimate custom gene carriers. The action still requires a player-controlled pawn, real map placement, no EMP disruption, enough Nanite Reserve and a defined WNG_ReplicatorMatter output. Pawns without the active reserve cannot fabricate blocks. No Queen/Sovereign/Temporary-Asuran block command authority is granted by fabricating loose blocks.
